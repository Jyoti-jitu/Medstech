# MedsTech – Premium Healthcare Technology & Digital Solutions Platform

A world-class, modern, fully responsive corporate website and healthcare technology platform built for **MedsTech**.

> **Brand Positioning:** *"Your Technology Partner in Modern Healthcare."*  
> **Headline:** *"Transforming Healthcare Through Technology."*

---

## 🚀 Live Local Server & URLs

The platform is running on `http://localhost:3000`:

| Page / Route | Purpose & Key Features |
|---|---|
| **[`/`](http://localhost:3000/)** | **High-Converting Corporate Homepage** with Hero visual, Capability pillars, Services overview, Product showcase, Why Choose Us, 7-Stage Process, Case Studies, About, and Contact Enquiry. |
| **[`/services`](http://localhost:3000/services)** | **Services Hub** detailing Doctor Websites, CMS, HMS, Customized Portals, Mobile Apps, and Healthcare R&D. |
| **[`/services/doctor-website-development`](http://localhost:3000/services/doctor-website-development)** | Tailored websites for physicians, cardiologists, surgeons, and specialists. |
| **[`/services/clinical-management-system`](http://localhost:3000/services/clinical-management-system)** | Advanced EMR, digital prescriptions, queue management, and clinic billing. |
| **[`/services/hospital-management-system`](http://localhost:3000/services/hospital-management-system)** | Modular enterprise hospital management system (18 functional modules). |
| **[`/services/customized-healthcare-websites`](http://localhost:3000/services/customized-healthcare-websites)** | Portals for hospitals, diagnostic centres, nursing homes, and health institutions. |
| **[`/services/mobile-application-development`](http://localhost:3000/services/mobile-application-development)** | Native Android (Kotlin) & iOS (Swift) patient and doctor apps. |
| **[`/services/research-and-development`](http://localhost:3000/services/research-and-development)** | AI, DICOM computer vision, predictive healthcare analytics & institutional research. |
| **[`/products`](http://localhost:3000/products)** | **Product Ecosystem:** MedsTech Clinical, Hospital, Connect, Digital, and Research. |
| **[`/demo`](http://localhost:3000/demo)** | **Live Clinical & Hospital Simulator:** Interactive Doctor EMR, Prescription Builder, Reception Token Dispenser, and Bed Matrix. |
| **[`/rd`](http://localhost:3000/rd)** | **Healthcare R&D Gateway:** Deep dive into AI, DICOM processing, and institutional proposal form. |
| **[`/portfolio`](http://localhost:3000/portfolio)** | **Case Studies:** Filterable project showcase across clinics, hospitals, mobile, and R&D. |
| **[`/about`](http://localhost:3000/about)** | **About MedsTech:** Vision, Mission, Core Values, Leadership Team, and Milestones. |
| **[`/contact`](http://localhost:3000/contact)** | **Business & Scoping Enquiry:** Validated contact form, direct WhatsApp, Google Maps, and office contacts. |
| **[`/admin`](http://localhost:3000/admin)** | **Protected Admin Console:** Lead management, consultation tracking, enquiry status update, inspection modal, notes editing, and pipeline analytics. |

## 🛠 Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript 5.4
- **Styling:** Tailwind CSS with custom medical theme tokens
- **Icons:** Lucide React
- **Persistence:** Local JSON `.data/enquiries.json` with REST APIs
- **SEO:** OpenGraph metadata, JSON-LD Schema (MedicalBusiness / SoftwareApplication), dynamic Sitemap (`/sitemap.xml`), and Robots (`/robots.txt`).
